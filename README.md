# Sticker Print Queue Service (Go + PostgreSQL)

An autonomous backend microservice designed for processing, validating, and queuing custom sticker and label orders for manufacturing pipelines.

## Features
- **Guard Clause Validation:** Fast, idiomatic Go validation returning explicit domain errors.
- **PostgreSQL Integration:** Context-aware database queries with strict timeout protection.
- **AI-Accelerated Workflows:** Built using AI prompting strategies to generate table-driven unit tests and optimize execution paths.
- **Table-Driven Unit Tests:** Comprehensive unit testing covering business logic limits and edge cases.

## Tech Stack
- **Language:** Go (Golang 1.22+)
- **Database:** PostgreSQL
- **Testing:** Native Go `testing` package
